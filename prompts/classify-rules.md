# 属性判定规则

把一个已完成任务判定为对 4 个属性（魅力 / 智力 / 体力 / 精神）的影响。

## 规则

1. **每个任务最多影响 2 个属性。**
2. **每个受影响的属性影响值为 +1 或 -1**（加分或扣分），其余属性为 0。
3. 根据任务标题和内容自主判断：
   - 积极 / 成长 / 完成类 → 加分到对应属性。
   - 明显负面行为（熬夜、拖延、无产出刷手机、暴食、冲动消费、争吵等）→ 扣分到对应属性。
   - 中性、日常琐事或无法判断 → 全 0（不给分）。
4. 常见映射（仅参考，以任务实际内容为准）：
   - **智力**：学习、读书、写作、解题、上课、复盘、工作产出
   - **体力**：健身、跑步、运动、早睡、体检、做饭
   - **魅力**：社交、约会、维护关系、理发、穿搭、公开表达
   - **精神**：冥想、散步放空、情绪处理、心理咨询、感恩记录
   - 扣分例：熬夜 → 体力-1；拖延 / 无产出刷手机 → 精神-1；暴食 → 体力-1
5. **判定标准：宁缺毋滥。** 拿不准就给 0 分，不要强行给分。

## 输出格式

对单个任务的判定输出为：
```
{ "effects": { "charm": 0, "intelligence": 0, "stamina": 0, "spirit": 0 }, "reason": "一句话理由" }
```
